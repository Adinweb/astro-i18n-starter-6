## Project Scope

Atlas Cloud needed a bilingual documentation and customer telemetry portal serving engineering teams across Europe and the Middle East without maintaining runtime servers.

## Technical Delivery

- **Zero-Runtime Documentation:** Built with Astro static collections, localized slugs, and per-locale Atom feeds.
- **Instant Multilingual Search:** Static Pagefind indexing paired with Persian orthography expansion delivers instant query results across all guides.
- **Accessible Interface:** WCAG-verified contrast presets, keyboard-navigable search drawers, and strict reduced-motion fallbacks.
