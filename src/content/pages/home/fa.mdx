# به استارتر چندزبانه آسترو خوش آمدید

این یک قالب مدرن و آماده برای تولید است که به صورت بومی از زبان‌های راست‌چین (RTL) مانند فارسی و عربی و زبان‌های چپ‌چین (LTR) پشتیبانی می‌کند.

ویژگی‌های کلیدی:
- ترجمه‌های زمان کامپایل با Paraglide JS بدون سربار اجرایی
- مسیریابی تمیز بدون پیشوند برای زبان پیش‌فرض
- مجموعه‌های محتوای متقارن با نامک‌های (slugs) ترجمه‌شده
- استایل‌دهی با Tailwind CSS v4 بر پایه ویژگی‌های منطقی (Logical Properties)
