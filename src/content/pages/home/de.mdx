# Willkommen beim Astro i18n Starter

Dies ist ein modernes, produktionsreifes mehrsprachiges Starter-Template mit erstklassiger RTL- und LTR-Unterstützung.

Hauptmerkmale:
- Übersetzungen zur Kompilierzeit via Paraglide JS
- Saubere URLs ohne Präfix für die Standardsprache
- Symmetrische Content Collections mit übersetzten Slugs
- Tailwind CSS v4 mit logischen Eigenschaften
