## Architecture Built for Multilingual Delivery

This starter combines Astro v7 static site generation with native bidirectional layout primitives, Paraglide compiled translations, and a Single Source of Truth configuration in `app.config.json`.

- **Prefix-less Default Locale:** The default language renders cleanly at `/` while secondary locales live under localized prefixes (`/fa/`, `/de/`, `/ar/`).
- **Logical RTL/LTR Discipline:** Directional spacing, borders, gradients, and scroll animations mirror automatically between LTR and RTL scripts.
- **Zero-Runtime Search & Feeds:** Static Pagefind indexing (with Perso-Arabic ZWNJ and numeral normalization), Atom 1.0 RSS feeds, and branded Open Graph cards generate at build time.
