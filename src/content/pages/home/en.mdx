# Welcome to Astro i18n Starter

This is a modern, production-grade multilingual starter with first-class RTL and LTR support.

Key features:
- Compile-time translations via Paraglide JS
- Clean prefix-less default locale routing
- Symmetrical Content Collections with translated slugs
- Tailwind CSS v4 with logical properties and semantic tokens
