در **نسخه ۱.۰** فرآیند شخصی‌سازی سریع برای پروژه‌های مشتریان ساده‌تر شده است تا تیم‌های توسعه بتوانند وب‌سایت‌های سریع و استاتیک را بدون نیاز به نگهداری سرور بک‌اند منتشر کنند.

## پالت‌های رنگی OKLCH و مدیریت فونت

به‌جای ویرایش پراکنده متغیرهای CSS، فایل `app.config.json` مجموعه‌ای از پالت‌های آماده OKLCH و جفت‌فونت‌های فارسی و لاتین را ارائه می‌دهد. تنها با یک دستور می‌توانید هویت برند و آیکون‌های وب‌اپلیکیشن را به‌روزرسانی کنید:

```bash
npm run site:init -- --name="Brand Studio" --preset=emerald --og-mode=branded --yes
```

## تولید خودکار کارت‌های Open Graph

با فعال‌سازی `socialCardMode: "branded"`، در زمان بیلد برای تمامی صفحات، مقالات وبلاگ و پروژه‌ها تصاویر PNG اختصاصی با رنگ‌بندی برند ساخته می‌شود.

## فرم‌های استاتیک و مدیریت رضایت

کامپوننت‌های `ContactForm` و `NewsletterBanner` پیام‌ها را مستقیماً به API هدلس پیکربندی‌شده ارسال می‌کنند و در صورت نبود اندپوینت، مسیر ایمیل امن یا پیام وضعیت مناسب را نمایش می‌دهند.
