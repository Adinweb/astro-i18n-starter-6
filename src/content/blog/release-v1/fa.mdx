# انتشار نسخه ۱.۰

امروز انتشار رسمی نسخه اول استارتر چندزبانه آسترو را اعلام می‌کنیم. این نسخه با هدف ارائه بستری کاملاً هماهنگ برای سایت‌های استاتیک چندزبانه با پشتیبانی پیش‌فرض از راست‌چین عرضه شده است.
