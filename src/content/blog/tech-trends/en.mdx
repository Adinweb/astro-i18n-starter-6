Delivering crisp bilingual experiences in English and Persian requires treating bidirectional typography and client-side search normalization as first-class architectural concerns rather than late CSS overrides.

## Logical Styling & Motion Choreography

All spacing, borders, and slide transitions rely on logical axes (`ms-*`, `me-*`, `start-*`, `end-*`, `text-start`). Horizontal reveal attributes like `data-trig-direction="start"` invert automatically between LTR and RTL documents, while `resolveMotion()` respects both explicit user preference and OS `prefers-reduced-motion`.

## Perso-Arabic Pagefind Normalization

Persian search queries frequently mix Arabic/Persian letter variants (`ي`/`ی`, `ك`/`ک`), Eastern numerals (`۱۲۳`), and zero-width non-joiners (ZWNJ). At build time, `scripts/index-pagefind.mjs` normalizes indexed tokens so static client search finds matches accurately across keyboards and dialects.
