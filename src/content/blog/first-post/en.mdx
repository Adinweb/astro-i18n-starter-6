Welcome to our first article! This walkthrough demonstrates localized slugs, symmetrical content collections, and RTL-safe technical publishing.

## Symmetrical Content Collections

Every page and article group lives inside a single folder where each locale owns a sibling MDX file alongside shared artwork:

```text
src/content/blog/first-post/
├── first-post.png
├── en.mdx
├── de.mdx
├── fr.mdx
├── fa.mdx
└── ar.mdx
```

## Localized Routing and Hreflang

- Slugs are translated natively per language (`first-post`, `erste-post`, `اولین-پست`).
- Alternate language URLs are wired automatically into `<link rel="alternate" hreflang="...">` and the header switcher.

## RTL-Safe Technical Prose

Code blocks and mathematical expressions remain isolated in `ltr` directionality even inside Persian and Arabic layouts, while tables and blockquotes mirror cleanly via CSS logical properties.
