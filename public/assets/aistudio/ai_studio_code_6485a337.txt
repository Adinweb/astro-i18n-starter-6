### 2. Tailwind v4 Theme & Semantic Token Mapping (Zero Raw Colors)
- **Remove ALL `dark:*` utilities** and **remove ALL raw palette/hex colors** (`bg-white`, `bg-black`, `text-white`, `slate-*`, `gray-*`, `zinc-*`, `blue-*`, `indigo-*`, `emerald-*`, `red-*`, `amber-*`, `#hex`, `rgb(...)`). Our OKLCH tokens automatically adapt across light and dark modes.
- **Map colors exclusively to these semantic Tailwind utilities** (defined in `src/styles/global.css`):
  - **Page & Surfaces**: `bg-bg` (page background), `bg-surface` (cards/inputs/panels), `bg-surface-hover` (hover/subtle fill), `border-border` (dividers/outlines)
  - **Typography**: `text-fg` (primary ink), `text-muted` (secondary/body/caption copy)
  - **Brand & Status Roles** *(always pair solid fills with their `-fg` text token for WCAG AA contrast)*:
    - Primary brand: `bg-primary text-primary-fg` (accents: `text-primary`, `bg-primary/10`, `border-primary/30`)
    - Secondary: `bg-secondary text-secondary-fg`
    - Accent: `bg-accent text-accent-fg`
    - Neutral dark pill/surface: `bg-neutral text-neutral-fg`
    - Status: `bg-info text-info-fg`, `bg-success text-success-fg`, `bg-warning text-warning-fg`, `bg-error text-error-fg`
  - **Hero / Media Scrims (mode-independent dark layer)**: `bg-hero-base`, `text-hero-fg`, `bg-scrim`
  - **Frosted Glass Tokens**: `bg-glass`, `bg-glass-hover`, `border-glass-border`, `bg-glass-control`, `shadow-glass`
- **Compose Shared Component Classes (Never Re-declare Buttons, Chips, or Glass)**:
  - Primary CTA button/link → `class="cta"` (add sizing like `h-11 px-6` only if needed)
  - Secondary outlined button/link → `class="btn-secondary"`
  - Secondary button over dark hero artwork → `class="btn-hero-secondary"`
  - Frosted glass card/panel → `class="glass-surface"`
  - Control inside glass bar → `class="glass-control"`
  - Subtle button on solid panel → `class="ghost-control"`
  - Filter/tab/tag pill → `class="chip"` (auto-highlights when `aria-selected="true"`, `aria-current="true"`, or `aria-current="page"`)
  - Badge over dark media/hero → `class="hero-badge"`
  - Section eyebrow/kicker label → `class="section-kicker"`

### 3. Strict RTL-Native Discipline (`en`, `de`, `fr` LTR + `fa`, `ar` RTL)
- **100% CSS Logical Properties — Physical Directions Are Forbidden**:
  - `ml-*` / `mr-*` → `ms-*` / `me-*`
  - `pl-*` / `pr-*` → `ps-*` / `pe-*`
  - `left-*` / `right-*` → `start-*` / `end-*`
  - `text-left` / `text-right` → `text-start` / `text-end`
  - `border-l-*` / `border-r-*` → `border-s-*` / `border-e-*`
  - `rounded-l-*` / `rounded-r-*` → `rounded-s-*` / `rounded-e-*`
  - Directional gradients (`bg-gradient-to-r`) → logical `bg-linear-to-e` (or `rtl:bg-linear-to-l`)
- **Directional Icons & Keyboard Navigation**:
  - Add `rtl:rotate-180` to directional arrows/chevrons (`arrow-right`, `chevron-right`, `chevron-left`).
  - In horizontal keyboard handlers (`ArrowLeft` / `ArrowRight`), check `document.documentElement.dir === 'rtl'` and mirror step direction.
- **Bidirectional Inputs, Numerals & Typography**:
  - Never hardcode `font-sans` / `font-serif` overrides; `global.css` binds Latin, `Vazirmatn` (`fa`), and `Noto Sans Arabic` (`ar`) via `:lang()` and automatically zeroes `letter-spacing` on RTL scripts.
  - On LTR-valued inputs (`type="email"`, `type="tel"`, `type="url"`, `type="datetime-local"`), set `dir="ltr"` and `class="... text-start rtl:text-end"`.
  - Wrap inline ASCII codes/IDs (`#MC-104`, `ISO-15189`) in `<bdi dir="ltr">`, and wrap mixed Arabic-Indic ratio strings (like `٢٤/٧`) in Unicode LTR isolate `\u2066...\u2069`.
