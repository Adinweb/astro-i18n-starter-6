**Astro i18n Starter** is a production-ready static site foundation built for multilingual, bidirectional web projects. Every layer—from routing and content schemas to color tokens and scroll choreography—follows strict Single Source of Truth principles.

## Core Design Principles

1. **Symmetrical Content Collections:** Every page, article, and case study resolves per-locale routes and `hreflang` alternates automatically from a single folder structure.
2. **Accessible by Default:** Semantic HTML landmarks, WCAG-compliant focus rings, unified `data-motion` reduced-motion controls, and print-ready styles come built in.
3. **Zero Vendor Lock-in:** Pure SSG output deploys anywhere static files are hosted, with optional external API adapters for forms and newsletters.
