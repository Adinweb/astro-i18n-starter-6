<section id="rtl" class="scroll-mt-28">

## Native RTL/LTR Architecture

Directional styling relies exclusively on CSS logical properties (`ms-*`, `me-*`, `ps-*`, `pe-*`, `start-*`, `end-*`, and `text-start`). Code blocks remain strictly LTR for readability, while directional gradients (`bg-linear-to-r rtl:bg-linear-to-l`) and ChronoTrig slide offsets (`data-trig-direction="start"`) adapt automatically per locale.

</section>

<section id="design" class="scroll-mt-28">

## Design System & Brand Tokens

Semantic color roles live once in `src/styles/global.css` and resolve dynamically from `app.config.json` and `theme-presets.json`. Composable surface utilities (`.glass-surface`, `.layout-container`) and primitive UI controls (`<Button>`, `<IconButton>`, `<Icon>`) keep contrast, spacing, and typography consistent across every page.

</section>
